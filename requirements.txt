# Runtime and test dependencies, kept to what the harness actually imports.
#
# This file was previously a catalogue of an "AI stack" -- LangChain, LangGraph,
# Qdrant, sentence-transformers, Kafka, gRPC, boto3 -- none of which any module
# here imports. It made `pip install -r requirements.txt` a multi-hundred-megabyte
# download (sentence-transformers alone pulls in torch) before a reader could run
# a single test. Anything reinstated below should be something a file imports.
#
# Libraries with compiled extensions are given a compatible range rather than an
# exact pin. An exact pin on pydantic meant that anyone on a Python newer than
# the one CI happens to use had no wheel available, fell back to building
# pydantic-core from source, and failed at the first command in the README. The
# linter stays pinned for the opposite reason, noted below.

# --- test runner -------------------------------------------------------------
